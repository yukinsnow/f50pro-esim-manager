# 🧪 实验功能，缺乏充分验证

## 实际验证了什么

在一台 MU3356/B28、UFI-TOOLS 4.0.0 上验证：
- 标准 ISD-R SELECT、EID、配置列表、芯片信息及通知列表读取成功。
- 已登录 UFI Root API 能读取；未登录返回401。
- 不存在配置的请求、已启用配置删除请求被预检拒绝；**这不是成功写卡测试**。
- 前端20项模拟测试、后端7项离线测试、加密输入往返测试。

## 未验证什么

- 没有在真实卡上验证 enable、disable、nickname、delete、download、notification send 完整流程。
- 没有验证真实运营商 SM-DP+ 下载、确认码、策略限制、刷新后联网恢复、掉电恢复。
- 尚无多机型/多固件/多卡版本兼容矩阵；手机视觉效果和实际重启流程尚待验收。

## 使用前

请使用可丢失、可重新下载的测试配置与备用互联网。eSIM 卡的配置不是普通文件，删除后不一定可恢复；运营商激活码可能只能用一次，下载中断不一定可以再次使用。

不要以唯一可用卡测试。不要将后台开放到公网。公开 Issue 不要附EID、ICCID、IMSI、电话号码、激活码、确认码、登录口令或完整Root日志。

## 已知限制

- 当前AT索引固定0，仅适用于实测的物理SIM2映射。其他映射可能不可用。
- `read.lock` 目录异常退出后可能残留；先核对任务与进程，不要直接清锁、删任务并重放写入。
- 出现pending/unknown时设备可能仍在处理；不能把网页超时当成“没有写入”。
- 删除已启用配置被阻止，不等于删除停用配置已被证实安全。
- 通知发送后保留队列，不会自动清除，重复发送的行为由服务器决定。
- 加密输入用于减少命令日志暴露；HTTP页面代码可被篡改，不能宣称具有HTTPS等价安全性。
- 独立旧只读查看器不是公开包的依赖；不要并行读卡。
- UI昵称限制与后端字节限制可能不同，中文长昵称会被后端拒绝。
- RSA私钥为本机生成，root可读；这个机制不是对同机root的隔离边界。

**请把本项目当作需要审查和补充测试的实验原型，而非成熟商业LPA。**
